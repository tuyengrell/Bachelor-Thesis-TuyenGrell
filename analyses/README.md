# Analyses

Run after the three preprocessing scripts. Text output goes to `results_combined/`.

- `combined_analysis.py` – combined model, H3a–H3c and exploratory task interactions
  (4.3.1, 4.3.2, 4.3.5, Appendix C.3–C.4)
- `check_h2_role_contrast.py` – target vs distractor intensity contrast (4.1.3, 4.2.3)
- `check_distractor_intensity_valence.py` – distractor intensity split by target valence (4.1.3, 4.2.3)
- `check_selection_bias_h3a.py` – selection check for H3a (4.3.3, Fig. 4.9)
- `check_intensity_boundary.py` – cutoff, slope and boundary-picture checks (4.3.4, Appendix D.1)
- `check_intensity_interactions.py` – target intensity by congruency and valence (4.3.4)
- `power_analysis_target_intensity.py` – analytic and simulated power (3.5.8, 4.3.4, Appendix D.2)
- `check_intensity_replication.py` – target intensity contrast in all three tasks (4.4)
- `check_crosstask_picture_rt.py` – picture-level RT correlations across tasks (4.4, Fig. 4.11)
